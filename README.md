## ✦ About

Founder of **[BigSur Corp](https://bigsur.in)**, building practical software for real operational problems.
I like owning the whole stack: product, architecture, code, security and infrastructure.

I usually start with *"what problem are we actually solving?"* and only then pick the tools.

```text
problem  →  architecture  →  build  →  secure  →  ship  →  iterate
```
